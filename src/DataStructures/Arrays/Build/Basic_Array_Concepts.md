# Basic Array

## 📌 Overview

This example demonstrates the fundamental use of an Array as a linear data structure.

An Array stores elements in indexed positions, allowing direct access to an element when its index is known.

## 🧠 Example Structure

```text
Index:  0    1    2    3
Value: 10   20   30   40
```

The first element is located at index `0`, not `1`.

## 🔍 Main Concepts

### Access

An element can be accessed directly using its index.

```text
array[index]
```

Typical complexity:

```text
O(1)
```

### Traversal

To visit every element, the array must be traversed.

```text
O(n)
```

### Searching

A normal unsorted array may require checking elements one by one.

```text
O(n)
```

## 🎯 Learning Goal

This example provides the foundation for understanding more advanced Array operations and implementations in the rest of the section.
